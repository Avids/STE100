# Review mode output

Use this structure when the user asks to check, audit, review, or explain STE compliance.

## STE review

Give a concise table with these columns:

| Text / issue | Rule area | Finding | Correction |
|---|---|---|---|

Include only meaningful issues. Do not create a row for every sentence if it is already acceptable.

Use rule references such as `1.3`, `2.1`, `3.6`, `5.1`, or `6.3` when the applicable rule is known from the bundled summary.

If exact dictionary status is uncertain, write `Dictionary verification required` instead of claiming that a word is approved or prohibited.

## Corrected STE version

After the review, provide the complete corrected text. Preserve the original document type and useful formatting.

## Optional compliance summary

For longer text, add a short summary with:
- sentence-length issues
- terminology consistency issues
- voice/verb issues
- dictionary-verification items

Do not give a numeric compliance percentage unless the user explicitly asks for one. If requested, explain that it is an internal review score, not an ASD certification score.
