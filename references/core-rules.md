# ASD-STE100 Issue 9 working rule summary

Use this file as the primary rule checklist. It paraphrases the rules needed for normal authoring and review and does not reproduce the full standard or dictionary.

## 1. Words

- Use approved dictionary words, technical nouns, and technical verbs.
- Use an approved word only as its approved part of speech and with its approved meaning.
- Use only approved verb/adjective forms.
- Permit technical nouns that belong to a recognized subject-field category. Keep one technical noun for one item; do not switch synonyms for the same item.
- Do not use regional, slang, or jargon words as technical nouns unless they are established industry terminology under the construction policy.
- Permit technical verbs that identify recognized subject-field processes. Technical verbs must obey the same verb rules as approved verbs.
- Do not use a technical noun as a verb, or a technical verb as a noun, unless that separate use is independently permitted.
- Default to American English spelling unless an applicable project, contract, client, or company directive requires another spelling. Preserve quoted text exactly.

## 2. Multi-word nouns

- Prefer multi-word nouns of three words or fewer.
- If an official technical noun has more than three words, write the full official term first. Then use a clear shorter form, approved abbreviation, or careful hyphenation when appropriate.
- Do not change an official technical noun if the change could alter its technical meaning.
- Use prepositions or a different sentence construction to break up long noun clusters.

## 3. Verbs

- Prefer simple verb forms: infinitive, imperative, simple present, simple past, simple future, and permitted past participle as adjective.
- Avoid complex auxiliary constructions.
- Use an `-ing` form only when it is an approved word, a technical noun, or a modifier in a technical noun.
- Use active voice. In descriptive writing, passive voice is permitted when the agent is genuinely unknown or unimportant and an active rewrite would invent an agent.
- Describe an action with a verb rather than a nominalized action noun when practical.
- Avoid phrasal verbs when a clear single verb or different construction is available.

## 4. Sentences

- Write short, direct, unambiguous sentences.
- Do not omit necessary words and do not use contractions merely to shorten the sentence.
- Use vertical lists for complex information.
- Use connecting words and phrases when they make the relation between sentences explicit.
- Use articles and demonstrative adjectives when needed for clarity.

## 5. Procedural writing

- Maximum: 20 words per procedural sentence.
- Put one instruction in each sentence, except when actions truly occur at the same time.
- Use the imperative/command form for instructions.
- If the reader must know a condition first, put the condition first, then a comma, then the command.
- Notes give information only. Do not put instructions, requirements, or limits in notes.
- A note sentence can have a maximum of 25 words.
- Safety instructions within procedures also obey the 20-word procedural limit.

## 6. Descriptive writing

- Give information gradually.
- Use repeated key words and key phrases to maintain logical continuity.
- Maximum: 25 words per descriptive sentence.
- Use paragraphs to group related information.
- Keep one topic in each paragraph.
- Use no more than six sentences in a paragraph.
- Do not use the imperative form in purely descriptive text.

## 7. Safety instructions

- Use the applicable project/industry signal word or safety category to identify the level/type of risk.
- Start with a clear condition or command.
- State the hazard, risk, or possible result clearly.
- Do not invent a hazard classification. Preserve the project safety terminology if supplied.

## 8. Punctuation and word count

- Do not use semicolons. Split the text into separate sentences.
- Use hyphens only to connect words that are directly related.
- Use parentheses only for clear supporting functions such as references, identifiers, abbreviations, alternatives, or short explanations.
- In a vertical list, treat the colon as the end of the introductory sentence for word-count purposes; treat each list item as a new sentence.
- Text in parentheses counts as one word in the containing sentence, but the parenthetical text must also be checked as its own sentence when applicable.
- For word counting, treat numbers, numbers with units, abbreviations, alphanumeric identifiers, quoted text, titles/headings/labels, and proper names as single elements where Issue 9 permits this treatment.
- Hyphenated words count as one word.

## 9. Writing practices

- If a word-for-word replacement is not sufficient, use a different sentence construction.
- Use each approved word only in its permitted meaning and grammatical function.
- Avoid phrasal verbs.
- Keep terminology and wording consistent.
- Use pronouns only when the referent is clear.
- Avoid vague uses of `this`; add the noun when needed (for example, `this condition`, `this test`, `this cable`).
- Prefer clear English instead of unnecessary Latin abbreviations.
- Use inclusive, neutral language.
- Use possessive forms only when they do not create ambiguity.

## Frequent STE corrections

Use these only when the meaning is correct in context:
- `shall` -> usually `must` for a requirement.
- `should` -> do not automatically change. If it is truly mandatory, use `must`; if it is a recommendation, preserve that weaker meaning with a clear construction.
- `therefore` -> `thus` or `as a result`.
- `since` when it means cause -> `because`.
- `test` as a verb -> rewrite with `test` as a noun when required by the STE dictionary (for example, `do the test`). Do not change an established construction technical verb solely under this rule if the construction terminology policy permits it.

## Final check

Before returning text:
1. Confirm the technical meaning did not change.
2. Check sentence-length limits by text type.
3. Check active voice and imperative use.
4. Check terminology consistency.
5. Check for long noun clusters, phrasal verbs, semicolons, vague pronouns, and unnecessary complexity.
6. Check that construction technical terms were preserved when appropriate.
